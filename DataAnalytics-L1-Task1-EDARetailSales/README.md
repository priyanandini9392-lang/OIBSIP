# EDA Retail Sales Analysis

## Internship
Oasis Infobyte Data Analytics Internship

## Task
Task 1 - Exploratory Data Analysis on Retail Sales Data

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset.
The objective is to understand sales and profit patterns and identify important
business insights from the data.

## Dataset
The dataset used in this project is:

Global_Superstore(CSV).csv

The dataset contains 1000 records and 24 columns.

## Objectives
- Understand the structure of the retail sales dataset
- Clean and preprocess the data
- Analyze sales and profit
- Analyze sales by category and sub-category
- Analyze monthly and quarterly sales trends
- Analyze customer segments
- Study correlations between numerical variables
- Generate useful business insights

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Analysis Performed
1. Dataset loading and inspection
2. Data cleaning
3. Date conversion
4. Sales analysis
5. Sales by category
6. Sales by sub-category
7. Profit by category
8. Monthly sales trend
9. Quarterly sales trend
10. Customer segment analysis
11. Correlation analysis
12. Correlation heatmap
13. Key business insights

## Key Insights
- Sales vary across different months and quarters.
- Technology is the highest-profit category in the analysis.
- Different sub-categories contribute differently to total sales.
- Sales, quantity, profit and shipping cost show varying degrees of correlation.
- Discounts have a negative relationship with profit.

## Project Files

## Conclusion
The exploratory analysis helps understand retail sales performance,
profitability, customer segments and sales trends. The insights can be
used to support better business and sales decisions.
